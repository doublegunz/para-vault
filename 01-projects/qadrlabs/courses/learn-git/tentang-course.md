# Learn Git: Master Version Control from Scratch

## Deskripsi
Learn Git from zero. Master commits, branches, merges, remote repos, GitHub, pull requests, rebasing, and professional collaboration workflows step by step.

## Konten
Every professional developer uses Git. It tracks every change to your code, lets you experiment safely with branches, collaborate with teams, and recover from mistakes. Whether you are working solo or in a team of fifty, Git is the foundation of modern software development.

This course teaches Git from scratch using the command line. You will start with your first repository and commit, then progress through branching, merging, remote repositories with GitHub, pull requests, collaboration workflows, and advanced techniques like rebasing and cherry-picking. Each lesson builds a real project (a personal website) so every Git command has a practical context.

Unlike tutorials that list commands without context, this course shows you why each command exists, what problem it solves, and what happens internally when you run it. You will understand Git, not just memorize it.

**This course is for you if:**
- You are a beginner who has never used Git
- You use Git but only know add, commit, and push (and panic when something goes wrong)
- You want to understand branching, merging, and pull requests for team collaboration
- You are preparing for a developer job where Git skills are expected

**Prerequisites:**
- Basic command line knowledge (cd, ls/dir, mkdir)
- A code editor installed (VS Code recommended)
- No prior Git experience required

**By the end, you will have:**
- A solid understanding of how Git tracks changes internally
- The ability to create repositories, commit changes, and view history
- Branching and merging skills, including resolving merge conflicts
- Experience with GitHub: push, pull, clone, fork, and pull requests
- Knowledge of professional workflows: Gitflow, feature branches, code review
- Advanced skills: stash, cherry-pick, rebase, amend, reset, tags
