Lesson 1 — What Is Machine Learning?
short description: Build the right mental model of machine learning, its main problem types, and the workflow you will use throughout the course.

Lesson 2 — Setting Up Google Colab
short description: Set up Google Colab, run your first notebook, import ML libraries, load a dataset, and save your work to Drive.

Lesson 3 — NumPy and pandas Essentials
short description: Learn the NumPy and pandas essentials for creating arrays, DataFrames, selecting data, filtering rows, and loading CSV files.

Lesson 4 — Exploring and Visualizing Data
short description: Explore real data with pandas, matplotlib, and seaborn using summaries, distributions, relationships, and correlation heatmaps.

Lesson 5 — The Machine Learning Workflow
short description: Learn the supervised ML workflow: build X and y, split data, train with fit, predict, and check model quality.

Lesson 6 — Your First Regression Model
short description: Train a linear regression model on California Housing data, evaluate it with R2 and MAE, and interpret what it learned.

Lesson 7 — Logistic Regression for Classification
short description: Switch from regression to classification by training logistic regression on Iris data and reading accuracy, reports, and probabilities.

Lesson 8 — Decision Trees and K-Nearest Neighbors
short description: Train decision tree and KNN classifiers, inspect how they work, tune k, and compare them fairly against logistic regression.

Lesson 9 — Measuring Model Performance
short description: Measure regression and classification models with the right metrics, and learn why accuracy alone can mislead.

Lesson 10 — Overfitting, Underfitting, and Train/Test Discipline
short description: Diagnose overfitting and underfitting by comparing training and test scores across model complexity levels.

Lesson 11 — Handling Missing Data and Categorical Features
short description: Clean real Titanic data by finding missing values, imputing them, and encoding text categories for scikit-learn models.

Lesson 12 — Feature Scaling
short description: Learn when feature scaling matters by applying StandardScaler and MinMaxScaler, then comparing model performance before and after.

Lesson 13 — Capstone: Build an End-to-End Predictor
short description: Build a complete Titanic survival predictor from raw data through exploration, cleaning, modeling, evaluation, and new predictions.

Lesson 14 — What's Next
short description: Review the full course, turn the ML workflow into a reusable checklist, avoid common pitfalls, and map your next learning steps.
