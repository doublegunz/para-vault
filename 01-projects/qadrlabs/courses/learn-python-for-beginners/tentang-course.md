# Learn Python for Beginners: From Zero to Your First Data Project

## Deskripsi
Learn Python from scratch. Master variables, lists, dictionaries, functions, file handling, and get a first taste of Pandas and Matplotlib for data analysis.

## Konten
Python is the most popular language for data science, automation, and general-purpose programming. Its clean syntax, massive library ecosystem, and gentle learning curve make it the ideal first (or second) programming language.

This course takes you from absolute zero to writing Python that reads files, processes data, and creates simple visualizations. Instead of isolated exercises, you will build toward a practical goal: a **mini data analysis project** that reads sales data from a CSV file, calculates summaries, and displays charts. This gives every concept a reason to exist.

If you already know SQL from the MySQL course, Python is the natural next step. SQL extracts data from databases. Python analyzes, visualizes, and models that data. Together, they form the core toolkit for any data role.

**This course is for you if:**
- You have never written a line of Python before
- You want to learn Python specifically for data analysis and data science
- You know SQL and want the next skill in the data science pipeline
- You want a solid foundation before learning Pandas, NumPy, and machine learning

**By the end, you will have:**
- A clear understanding of Python syntax, data types, control structures, and functions
- Experience with lists, dictionaries, and list comprehensions
- The ability to read and write CSV files
- A first taste of Pandas and Matplotlib for data analysis and visualization
- A mini project that ties all concepts together
