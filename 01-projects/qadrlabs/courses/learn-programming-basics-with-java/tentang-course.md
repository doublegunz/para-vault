# Learn Programming Basics with Java: Algorithms from Zero

## Deskripsi
```
Learn to think like a programmer. Design algorithms with algorithmic notation, then turn them into working Java programs: variables, decisions, loops, functions, arrays, searching, and sorting.
```


## Konten

```
Learning to program is not the same as memorizing a programming language. Before you write a single line of code, you need to know how to break a problem into small, clear steps that a computer can follow. That list of steps is called an algorithm, and it is the real skill behind every program you will ever write. Once you can design an algorithm, switching from one language to another becomes much easier, because the thinking stays the same and only the syntax changes.

This course teaches programming fundamentals from the very beginning, with algorithms at the center. You do not need any previous programming experience. Every lesson follows the same pattern: start with a small, concrete problem, design the solution in algorithmic notation (a structured, language-neutral way of writing algorithms with Program, Dictionary, and Algorithm sections), and then translate that notation into a complete Java program that you compile and run yourself in the terminal. Each lesson ends with common mistakes to fix and exercises to practice, so you build both the thinking and the typing habits.

Java is the implementation language because it is widely used, strict about data types, and clear about structure, which makes the link between an algorithm and its code easy to see. The course uses JDK 21 (a long-term support release) and only the Java standard library, so there are no extra packages to install. It finishes with a mini project: a console Student Grades application that stores student scores, calculates averages and letter grades, searches for a student, and sorts the results, bringing together everything you have learned.

**Prerequisites:**
- No previous programming experience required
- A computer running Linux, Windows, or macOS with terminal access
- A text editor such as Visual Studio Code
- An internet connection to install JDK 21

**By the end, you will have:**
- A clear understanding of what programs and algorithms are, and how to describe a solution step by step
- The habit of writing algorithms in algorithmic notation before writing code
- A working JDK 21 setup and a clear picture of the javac and java compile-and-run workflow
- A solid grasp of variables, data types, operators, expressions, input, and output
- Confidence with decisions (if, nested conditions, multiple cases) and repetition (while, repeat-until, for)
- Experience splitting programs into procedures and functions, including simple recursion
- Practice with arrays, two-dimensional arrays, strings, and records
- Classic searching and sorting algorithms written in notation and implemented in Java
- A console Student Grades application that ties every concept together
```

## Daftar Modul

### 1. `Module 1 - Getting Started`

```
Understand what programs and algorithms are, learn to write algorithms in algorithmic notation, and set up Java to run your first program.
```


- Lesson 1 - What Is Programming and What Is an Algorithm?
    lesson short description
    ```
    Learn what a program is, what an algorithm is, and how to describe a solution as clear, ordered steps using everyday examples before touching any code.
    
    ```
- Lesson 2 - Writing Algorithms in Algorithmic Notation
    lesson short description
    ```
    Write your first algorithms with the Program, Dictionary, and Algorithm sections, and learn the basic notation for assignment, input, and output.
    
    ```
- Lesson 3 - Installing Java and Your First Program
    lesson short description
    ```
    Install JDK 21, compile and run Hello World with javac and java, and translate a simple algorithm from notation into a complete Java program.
    
    ```

### 2. `Module 2 - Data and Expressions`

```
Store and process data with variables, constants, and data types, build calculations with operators and expressions, and talk to users through input and output.
```


- Lesson 4 - Variables, Constants, and Data Types
    lesson short description
    ```
    Declare variables and constants in the Dictionary section, choose the right data type for each value, and map them to Java types such as int, double, char, boolean, and String.
    
    ```
- Lesson 5 - Operators and Expressions
    lesson short description
    ```
    Calculate, compare, and combine values with arithmetic, relational, and logical operators, understand operator precedence, and convert between numeric types.
    
    ```
- Lesson 6 - Reading Input and Displaying Output
    lesson short description
    ```
    Turn input and output in notation into Java code with Scanner and System.out, format numbers neatly, and build small programs that read data and print results.
    
    ```

### 3. `Module 3 - Making Decisions`

```
Teach your programs to choose between paths with conditions, from a single if-then to nested conditions and multiple cases.
```


- Lesson 7 - If-Then and If-Then-Else
    lesson short description
    ```
    Write decisions with if-then and if-then-else in notation, implement them in Java, and solve problems such as checking even numbers and passing scores.
    
    ```
- Lesson 8 - Nested Conditions and Multiple Cases
    lesson short description
    ```
    Handle more than two outcomes with nested conditions, else-if chains, and the depend on notation, then implement them in Java with if-else and switch.
    
    ```

### 4. `Module 4 - Repetition`

```
Repeat steps automatically with while, repeat-until, and for loops, and learn the common loop patterns behind counting, summing, and finding extremes.
```


- Lesson 9 - While Loops
    lesson short description
    ```
    Repeat steps while a condition is true, design the loop condition and stopping point in notation, and implement while loops in Java without getting stuck forever.
    
    ```
- Lesson 10 - Repeat-Until and For Loops
    lesson short description
    ```
    Use repeat-until when steps must run at least once and for loops when the number of repetitions is known, then implement them in Java with do-while and for.
    
    ```
- Lesson 11 - Common Loop Patterns
    lesson short description
    ```
    Apply classic loop patterns to count items, sum and average values, find the minimum and maximum, and validate user input, with notation and Java for each.
    
    ```

### 5. `Module 5 - Modular Programs`

```
Split large programs into small, reusable pieces with procedures and functions, pass data through parameters, and solve problems with recursion.
```


- Lesson 12 - Procedures
    lesson short description
    ```
    Break an algorithm into named procedures, call them from the main algorithm, and implement them in Java as void methods to keep programs short and readable.
    
    ```
- Lesson 13 - Functions and Parameters
    lesson short description
    ```
    Write functions that receive parameters and return a value, understand input parameters and local variables, and implement them in Java as methods with return types.
    
    ```
- Lesson 14 - Recursion
    lesson short description
    ```
    Solve problems by having a function call itself, identify the base case and recursive case in notation, and implement factorial, power, and similar examples in Java.
    
    ```

```

    ```

    ```
- Lesson 17 - Working with Strings
    lesson short description

    ```

    lesson short description
    ```

    ```
