# Prompt voice over: Learn Rust for Beginners (rust-beginners-promo-vo)

Naskah voice over untuk versi video dengan suara. Hanya **audio** dari klip ini yang dipakai di video (layar tetap 100% motion graphics), tetapi format prompt mengikuti [[Prompt video promosi qadrlabs 35473f1d661580b3a541ea4c8a521ab1|prompt promosi qadrlabs]].

## Naskah lengkap

Target penonton: pemula yang tertarik belajar programming. Tujuan course: melatih dasar-dasar programming, dengan Rust sebagai bahasanya. Karena itu naskah memakai bahasa sehari-hari, tanpa istilah teknis seperti compiler atau command-line.

| Part | Pesan | Dialog |
|---|---|---|
| 1 | Pemula yang ingin belajar | Want to learn programming, but not sure where to start? Start from zero. No experience needed. |
| 2 | Cara belajar: praktik langsung | One concept per lesson. Type it, run it, and when something breaks, you'll see how to fix it. |
| 3 | Yang dipelajari: dasar programming | Variables, conditions, loops, and functions. The basic building blocks every programmer needs. |
| 4 | Nama course + brand | Learn programming fundamentals from zero with Rust. Learn Rust for Beginners, at Koderlabs dot com. |

Total: 4 part x 8 detik, sekitar 30 detik termasuk end card.

## Cara menyimpan hasil

1. Generate setiap part dengan prompt di bawah.
2. Simpan hasilnya di folder ini (`sandbox/learning-video/videos/rust-beginners-promo-vo/voiceover/`) dengan nama `part-1.mp4`, `part-2.mp4`, `part-3.mp4`, `part-4.mp4`.
3. Rasio video apa pun boleh, karena hanya audionya yang dipakai.
4. Generate ulang sebuah part kalau kalimatnya terpotong, ada kata yang hilang, atau ada musik latar.
5. Jeda hening di awal dan akhir klip tidak masalah karena akan dipotong otomatis.

Pelafalan: "Koderlabs dot com" sengaja ditulis fonetik supaya model mengucapkan qadrlabs.com dengan benar. Di layar dan subtitle tetap ditulis `qadrlabs.com`.
