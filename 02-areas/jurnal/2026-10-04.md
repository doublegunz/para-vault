berikut template dokumentasi yang harus dibuat
```

1. Membuat file dokumentasi perubahan (walkthrough) dalam format Markdown (.md).
2. Menyimpannya ke dalam folder: _agent/walkthroughs/ dengan format nama:
   walkthrough_YYYY-MM-DD_HH-MM-SS_nama-tugas.md (contoh: walkthrough_2026-05-20_13-20-21_fitur-whatsapp.md).
3. Dokumentasi tersebut harus menjelaskan:
   - Perintah atau prompt yang saya ketikkan secara lengkap
   - Daftar file yang dimodifikasi/dibuat baru.
   - Ringkasan singkat mengenai perubahan/penambahan fungsi yang dilakukan.
   - Cara verifikasi/pengujian kode tersebut jika diperlukan.
   - Jika ada proses yang perlu saya lakukan di database server seperti ALTER TABLE atau CREATE TABLE, jangan Anda buatkan perintahnya di file untuk dijalankan lewat browser ataupun cron. Tetapi berikan perintahnya ke saya agar bisa saya jalankan di server. (run migration atau seeder)
```
